  <behavior>
    - getTodosForDate(state, key): 입력 state는 그대로, `[...list].sort((a,b)=>a.createdAt-b.createdAt)` 새 배열 반환. 키가 없으면 빈 배열.
    - addTodo(state, key, text): text.trim()이 빈 문자열이면 state 그대로 반환(Object.is(state, returned) === true). 그 외에는 `{id: crypto.randomUUID(), text: trimmed, done:false, createdAt: Date.now()}`를 해당 날짜 배열 끝에 append한 새 state 반환.
    - toggleTodo(state, key, id): 해당 id의 done 플래그를 뒤집은 새 todo로 교체한 새 state 반환. id 없으면 변경 없는 새 state(map만 통과).
    - editTodo(state, key, id, text): text.trim()이 빈 문자열이면 state 그대로 반환. 그 외에는 해당 id의 text를 trimmed로 교체한 새 state 반환.
    - removeTodo(state, key, id): 해당 id를 filter로 제거한 새 state 반환.
    - renderTodoList(container, todos, editingId): todos.length === 0 → container.replaceChildren(`<p class="empty">아직 할 일이 없습니다.</p>`). 1+ → container.replaceChildren(`<ul class="todo-list">{<li>×N}</ul>`).
    - renderTodoItem(t, isEditing): `<li data-id=t.id>` (+ `done`/`editing` 클래스) 안에 checkbox(.todo-checkbox, type=checkbox, checked=t.done) + body(`<span class="todo-text">` 또는 `<input class="todo-edit-input" type="text" value=t.text>` if isEditing) + `<button class="todo-edit">✎</button>` + `<button class="todo-remove">🗑</button>` 4 노드.
    - 사용자 텍스트 표시는 항상 `el.textContent = t.text` 또는 `input.value = t.text` (property 할당).
  </behavior>
