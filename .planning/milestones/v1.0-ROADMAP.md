# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-13
**Phases:** 1-4
**Total Plans:** 11
**Audit:** `tech_debt` verdict — 25/25 requirements WIRED, 0 blockers (VERIFICATION.md 2건 누락은 정보성 부채)

## Overview

날짜별 todo 관리 정적 웹앱 v1.0. 캘린더 월 그리드에서 날짜를 골라 그 날의 todo를 CRUD하며, `localStorage`로 새로고침 후에도 데이터가 유지된다. 빌드 도구·프레임워크 없이 `index.html` + 바닐라 JS 모듈로 동작하며, 저장 실패 시 배너로 우아하게 알린다.

## Milestone Summary

**Key Decisions:**

- 4-phase coarse roadmap (research P1+P2 → Foundation) — coarse granularity 우선
- 단일 storage 키 `hansung-todo:v1`, 단일 JSON blob 원자 쓰기
- 로컬 시간 `dateKey()` 헬퍼 + `toISOString` 전체 금지 (UTC 드리프트 0)
- `textContent`-only 렌더링 (`innerHTML` 금지) — XSS 방어 게이트
- 인라인 편집 (Enter/Esc/blur), 모달 없음 — 마크업 최소화
- 즉시 삭제 (확인·undo 없음) — 재추가 비용 낮음, v2 POL로 이연
- `monthGrid` Date overflow normalization으로 42셀 고정 — 분기 0개, 레이아웃 점프 0
- 인접달 셀은 `<div>` (data-key 부재로 자동 비활성) — `closest('[data-key]')` 가드
- 이중 신호 강조 (border-weight + color) — 색맹 안전
- `save()` boolean → throw 전환 (PERS-04) — 단일 실패 신호로 통합
- `commit()` always-apply-to-memory — 저장 실패해도 UI 일관성 유지

**Issues Resolved:**
